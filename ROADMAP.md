**Project:** DAB Control Suite  
**Status:** Initial Planning

# Vision

Build an open, modular and professional DAB/DAB+ ecosystem consisting of:

- Raspberry Pi server
- Native desktop applications
- REST API
- Modern web administration
- Automatic updates
- Backup & recovery
- Future hardware support

# MWI DAB Server

DAB+-Webradio auf Raspberry Pi Zero 2 W mit uGreen DAB Board.

## Komponenten

- uGreen DAB Board
- Si468x DAB-Empfänger
- radio_cli
- arecord
- ffmpeg
- Icecast2
- Flask-Webinterface

## Aktueller Stand

- DAB+-Senderliste aus ensemblescan__.json
- Senderwechsel per Weboberfläche
- I²S-Ausgabe
- MP3-Stream über Icecast

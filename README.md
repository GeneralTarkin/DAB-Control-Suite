# DAB Control Suite

A modern, network-enabled DAB/DAB+ radio server with a native desktop client, web administration, REST API, and automatic station management for Raspberry Pi and Windows. Based on DAB Board by uGreen.

DAB Control Suite transforms a Raspberry Pi with a supported DAB receiver into a powerful network-enabled radio server. It provides live audio streaming, a modern web administration interface, automatic station management, logo support, REST APIs, and a native Windows desktop application.

## Features

- 📻 DAB/DAB+ live reception
- 🌐 Network audio streaming
- 🖥 Native Windows desktop application
- ⚙ Modern web administration
- 🔍 Automatic station scanning
- 🖼 Station logo management
- ⭐ Favorites and dashboard selection
- 🔌 REST API
- 🔄 Automatic updates
- 💾 Backup and recovery
- 📡 Remote administration
